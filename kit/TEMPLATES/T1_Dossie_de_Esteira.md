# T1 — DOSSIÊ DE ESTEIRA (o produto real da deliberação)

```markdown
# DOSSIÊ · {nome da esteira} · {RODADA}
> Rótulo: [FICTÍCIA — criada para demonstração | REAL DOCUMENTADA (fonte) | RELATO (dono)]

## 1. A esteira em um parágrafo
O que faz, quem avalia hoje, volume, dado envolvido. Assunções marcadas [ASSUNÇÃO].

## 2. Convocação e pareceres (na íntegra em Pareceres/; aqui, o essencial de cada um)
Cartas convocadas nesta deliberação: P1–P4 (mesa fixa) + {P5? P6? convocáveis?} — gatilho de cada convocação: …
- **P1 Arquitetura/Engenharia:** … (classificação de viabilidade)
- **P2 Governança/Risco:** … (veredito: sem objeção / com condições / BLOQUEIO)
- **P3 Produto/MCP/Skills:** … (forma recomendada + building blocks)
- **P4 Dono da Esteira:** … (exceções + vetos de irrealismo, se houver)
- **P5 Segurança Adversarial** *(se convocada)*: … (três caixas + veredito)
- **P6 Dados/Avaliação** *(se convocada)*: … (procedência dos números + veredito)

## 3. Conflitos entre pareceres — EXPOSTOS
Onde os papéis apontam para lados opostos, e por quê. Um dossiê em que todos
concordam é sinal de papéis mal desenhados ou de desconforto editado.
A divergência é o conteúdo mais valioso desta seção — nunca a resuma até sumir.

## 4. Riscos
Os 3–5 que importam, cada um com: mecanismo, sinal antecipado, mitigação proposta (ou "sem mitigação conhecida").

## 5. Recomendação
Uma de: automatizar (com a forma do P3 e as condições do P2) / pilotar com amostra /
não automatizar agora (por quê, e o que mudaria a resposta) / devolver para instrução (com a pergunta específica).

## 6. O que segue para autoridade humana
A fila externa: as perguntas prontas para jurídico/compliance/comitê que o squad NÃO pode responder.
```
